# DLS Chat — Website

Informational website for **DLS Chat**, the messaging and community app from
One Dollar Launch Shop.

Plain HTML/CSS, no build step. Open `index.html` in a browser, or deploy the
folder to any static host (GitHub Pages, Netlify, Vercel, etc.).

```
index.html     page content
styles.css     styles
assets/        logo, coin artwork, favicon
```
