# DLS Chat — Website

Informational website for **DLS Chat**, the messaging and community app from
One Dollar Launch Shop.

Plain HTML/CSS/JS, no build step. Open `index.html` in a browser, or deploy the
folder to any static host (GitHub Pages, Netlify, Vercel, etc.).

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home |
| `features.html` | Feature tour |
| `rewards.html` | OneDollar Coins, wallet and withdrawals |
| `guidelines.html` | Community guidelines |
| `support.html` | Help centre / FAQ |
| `privacy.html` | Privacy policy |
| `terms.html` | Terms of service |

Shared files: `styles.css`, `script.js` (mobile menu, active nav link, footer
year), `assets/` (logo, coin artwork, favicon). The header and footer are
repeated in each page — update them in every file when changing navigation.
